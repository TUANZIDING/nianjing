如何启用官方 API？

把项目中的「服务配置示例v1.0.json」复制到「私有/服务配置v1.0.json」，填入自己的 Key 和已开通的模型 ID，选择每一层的服务后重启。图片和视频都就绪后，页面会启用 API 创作。独立音乐可稍后配置。

API 会按第三方规则产生费用；网页不会接收或显示你的 Key。适配器尚未付费实测，首次使用请先确认模型权限和账户用量。服务入口是候选清单，没有宣称合作关系。
