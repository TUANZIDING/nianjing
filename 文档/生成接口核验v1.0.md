# 念景生成接口核验 v1.0

核验日期：2026-10-09。范围：官方公开文档和官方页面搜索索引；未登录、未充值、未发送生成请求。下面是可供适配器使用的请求结构，全部模型须由用户配置，示例占位值不可直接调用。

## Vidu

统一根地址为 `https://api.vidu.cn`；请求使用 `Authorization: Token {API_KEY}` 与 `Content-Type: application/json`。

### 图片：POST /ent/v2/reference2image

当前文档列 `viduq2` 支持文生图、编辑和参考生图：`images` 可为0～7张，省略即文生图；`viduq1` 需要1～7张参考图。提示词上限2000字符。当前页面将 `images` 类型和部分示例写成字符串，但旧版正文及其他示例使用字符串数组，实际兼容性待调用核验。[当前图片合同](https://platform.vidu.cn/docs/api-reference/image-generation)、[旧版数组示例](https://docs.platform.vidu.cn/347178589e0)。

```json
{
  "model": "<配置的支持文生图的模型>",
  "prompt": "上半摄影、下半纸面水彩，以一条飘落的丝带连接两个世界",
  "aspect_ratio": "16:9",
  "resolution": "1080p"
}
```

参考生图在上述对象加入 `"images": ["<可访问图片URL或data URI>"]`。提交响应读取 `task_id`。

### 视频：POST /ent/v2/img2video

官方索引列 `viduq3-pro`、`viduq3-turbo`、`viduq3-pro-fast` 时长1～16秒，因此10秒有效；`images` 必须是仅含1张首帧图的数组，支持可访问URL或Base64 data URI。Q3支持1080p，默认 `audio=true`。单独配乐流程显式传 `false`；原生音画同出可传 `true`，但这不保证音乐可单独替换。`bgm` 在Q3无效，Q2的9/10秒也无效。[图生视频合同（本次读取官方索引，正文入口迁移）](https://platform.vidu.cn/docs/image-to-video)、[新Q3页面入口](https://platform.vidu.cn/docs/api-reference/video-models/vidu-q3/image-to-video)。

```json
{
  "model": "<配置的Q3图生视频模型>",
  "images": ["<首帧图片URL或data URI>"],
  "prompt": "纸页轻轻呼吸，丝带缓慢飘动，镜头轻推，保持拼接构图",
  "duration": 10,
  "resolution": "1080p",
  "audio": false,
  "off_peak": false
}
```

### 音频：POST /ent/v2/text2audio

官方索引明确支持音效和背景音乐BGM，列模型 `audio1.0`、`prompt` ≤1500字符、数值型 `duration` 2～10秒（默认10）；旧版可读正文提供10秒音效请求。以下音乐提示词是本项目示例；乐器控制、音乐质量及新账号可调用性均未实测。[当前官方索引合同](https://platform.vidu.cn/docs/text-to-audio)、[旧版可读正文](https://docs.platform.vidu.cn/331850541e0)。

```json
{
  "model": "<配置的文生音频模型>",
  "prompt": "10秒纯音乐，温柔钢琴与轻柔弦乐，舒缓优雅，无人声，结尾自然收束",
  "duration": 10,
  "seed": 0
}
```

提交为异步任务，响应读取 `task_id`；不是直接返回音频二进制。最终下载链接按下述任务接口获取。文件格式、Content-Type及真实音乐效果待实测。

### 查询：GET /ent/v2/tasks/{id}/creations

读取 `state`：`created`、`queueing`、`processing`、`success`、`failed`。成功时读 `creations[].url`，同项另有 `id`、`cover_url`、`watermarked_url`；失败读取 `err_code`。生成物URL有效24小时。旧指南散文曾写 `status=success`，适配器应以当前任务合同的 `state` 为准。[任务详情](https://platform.vidu.cn/docs/api-reference/task-management/task-detail)。

```json
{
  "id": "<任务ID>",
  "state": "success",
  "err_code": "",
  "creations": [{"id": "<生成物ID>", "url": "<下载URL>"}]
}
```

## 火山方舟

根地址 `https://ark.cn-beijing.volces.com/api/v3`；请求头 `Authorization: Bearer {API_KEY}`、`Content-Type: application/json`。模型ID或推理接入点由用户填写并在账号中开通。

### 图片：POST /images/generations

必填 `model`、`prompt`；`size` 与可用模型匹配。`response_format` 可为 `url` 或 `b64_json`，分别读取 `data[].url` 或 `data[].b64_json`；URL有效24小时。图像编辑按模型能力加入 `image`（URL/data URI或数组）。[图片API](https://docs.volcengine.com/docs/ark/image-generation-api?lang=zh&redirect=1)。

```json
{
  "model": "<已开通的生图Model ID>",
  "prompt": "上半摄影、下半纸面水彩，以飘落丝带连接两个世界",
  "size": "2K",
  "response_format": "url"
}
```

### 视频：POST /contents/generations/tasks

首帧图生视频使用 `content` 中的文本对象与 `image_url` 对象，图片的 `role` 设为 `first_frame`。10秒适用于文档列出的Seedance 2.x范围，但其他模型需单独核验。`resolution`、`ratio`、`generate_audio` 都有模型差异：Seedance 2.5首帧图生视频仅支持 `ratio=adaptive`；2.0可指定或adaptive。原生音频参数适用于支持该能力的2.x模型；独立音乐流程显式关闭。创建响应读取 `id`。[创建视频任务](https://docs.volcengine.com/docs/ark/create-video-generation-task-api?lang=zh)。

```json
{
  "model": "<已开通且支持这些参数的视频Model ID>",
  "content": [
    {"type": "text", "text": "纸页轻轻呼吸，丝带缓慢飘动，镜头轻推"},
    {"type": "image_url", "image_url": {"url": "<图片URL或data URI>"}, "role": "first_frame"}
  ],
  "duration": 10,
  "ratio": "adaptive",
  "resolution": "720p",
  "generate_audio": false
}
```

### 查询：GET /contents/generations/tasks/{id}

读取 `status`：`queued`、`running`、`cancelled`、`succeeded`、`failed`。成功读取 `content.video_url`；失败读取 `error` 对象。下载URL有效24小时，任务查询保留窗口为最近7天。不要把Vidu的 `success`/`state` 直接套用到方舟。[查询视频任务](https://docs.volcengine.com/docs/ark/get-video-generation-task-api?lang=zh)。

```json
{
  "id": "<任务ID>",
  "status": "succeeded",
  "content": {"video_url": "<下载URL>"}
}
```

## 权限与待验收事项

Vidu需要账号、API Key及积分；具体额度、当前模型权限、并发限制应在用户账号核验。[Vidu FAQ](https://platform.vidu.cn/docs/overview/faq)。方舟需开通相应模型；Seedance 2.5公开开通条件包含余额、储蓄计划或资源包等不同路径，不能把余额门槛写成唯一条件。[Seedance 2.5开通说明](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)。

本次仅确认公开合同结构；没有证明真实账号可调用、账单金额、延迟、成片质量、跨域下载或模型遵循提示词程度。Vidu网页迁移中存在新旧正文和索引差异，首次获授权调用时先验证最小请求、返回字段和文件类型，再放开完整创作流程。项目不设自己的收费或充值窗口；用户在第三方付费或配置自己的API，贡献者可补充经核验的适配和合作入口。
