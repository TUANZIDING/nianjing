# 双语界面扩展 v1.0

模式：Extension。延续既有米白纸张、墨色文字、陶土色点缀、真实四景素材和克制动态。保留主流程、锚点、表单字段、素材、配置路径与本地作品。

增加：页首中文 / EN按钮，双语静态文案、动态状态、提示词、示例介绍、无障碍名称与页面标题。英文采用本机Baskerville / Georgia衬线标题，中文继续Songti SC；英文长标题适当收紧字号和字距。小屏页首分两行，语言开关与导航不挤占。

语言选择：URL显式lang参数优先，其次本地记录，最后浏览器语言。不是英文时默认中文。使用zh / en状态值；原表单的布局值、模型与API参数不因文案翻译改变。

保留用户原话、自定情绪与音乐、已选文件和已有视频。翻译界面和模板，不调用语言模型翻译用户内容。切换不会重建输入区或播放器，不发起生成。英文时将官方服务名称、示例标题和解释写成自然英文；第三方网址保留已核验的官方入口。

默认代码为1.1，旧1.0保留作快照。采用0.2.0版本交付，独立记录双语验证与英文推广文案；没有远程发布动作。
