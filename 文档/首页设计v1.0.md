# 念景GitHub首页设计 v1.0

日期：2026-10-09。范围：GitHub项目介绍、英文首页、使用文档入口与概念主图。应用功能和本地创作界面沿用原版本。

## 个人项目布局参照

本轮直接读取公开仓库首页，提取布局结构，未复制其科研内容或封面素材：

- [research-evidence](https://github.com/TUANZIDING/research-evidence)：大幅封面、居中标题、短定位、入口导航、能力边界与文件索引。
- [Paper-AI-Research-Agent](https://github.com/TUANZIDING/Paper-AI-Research-Agent)：中英文入口、主图、简明标语、状态徽章、工作流、能力状态与快速开始。
- [trauma-master-academy](https://github.com/TUANZIDING/trauma-master-academy)：中英文内容与清楚的课程、用途及使用入口。
- [clinical-stats-languages-guide](https://github.com/TUANZIDING/clinical-stats-languages-guide)：图文结合，优先回答使用者的问题，并将实现状态说明清楚。

## 页面顺序与视觉语言

首屏主图 → 居中中英文标题与标语 → 语言、版本和检查状态 → 入口导航 → 三种创作场景 → 四景画廊 → 快速开始与实际界面 → 工作流 → 能力状态 → 可折叠API配置 → 共创与文档 → 维护者与来源。

默认中文，英文首页采用相同信息顺序。中文保留短英文标题及作品名，便于传播；英文首页提供完整英文介绍。没有填入虚构用户量、评价、合作品牌或成片成功率。

两张主图采用宽幅构图：米白手工纸、深墨线、暖金色、低饱和蓝色。题目与按钮用GitHub原生Markdown / 可保留HTML呈现，不把重要文字烘焙到图片中。画廊与应用截图采用两列排布，API细节折叠，减少首页技术密度。

GitHub宿主导航、按钮、页面颜色与字体遵循平台渲染；本轮整理仓库可控制的README内容布局。
