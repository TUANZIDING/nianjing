# 念景 · Nianjing v0.2.1

**GitHub首页视觉更新 / GitHub homepage refresh**

本版整理项目展示与文档，创作功能沿用v0.2.0。

This release refreshes the project presentation and documentation. Creation functionality is unchanged from v0.2.0.

- 参照维护者其他公开项目的布局，加入大幅封面、居中标题、语言入口、状态徽章和导航。
- 新增两张AI生成概念主图，分别呈现摄影与纸上绘画连接、三种日常创作场景。
- 默认中文首页，英文首页采用对应结构；四景画廊与实际应用截图独立展示。
- 使用入口提前，API细节折叠，能力状态与共创文档集中整理。
- 主图原始提示词、文件哈希与用途标签随项目保留。

- A wide cover, centered title, language links, status badges and navigation follow the maintainer's public project layout.
- Two new AI-generated concept artworks present photography meeting paper drawing and three everyday creative possibilities.
- The Chinese homepage and corresponding English page share one structure, with existing Muse films and actual application screenshots labeled separately.
- Quick start is easier to find, API detail is folded away, and capabilities and contribution documents are grouped.
- Exact artwork prompts, hashes and usage labels are included.

下载`Nianjing-projectv0.2.1.zip`，解压后在项目目录运行`node 创作服务v1.1.mjs`。需要Node.js 22+；媒体检查与合成需要FFmpeg和ffprobe。

Download `Nianjing-projectv0.2.1.zip`, unzip and run `node 创作服务v1.1.mjs` from the project folder. Use Node.js 22+; media validation and composition require FFmpeg and ffprobe.

新主图为概念图，不是生成短片或应用运行效果的证据。四段既有Muse短片、规则导演、离线API适配器和付费生成待实测的状态不变。此版没有部署公网创作服务。

The new artwork is conceptual, not generated-film or application-output evidence. Existing Muse films, the rule-based director, offline adapter checks and the untested paid-generation status remain unchanged. No public online creative service is deployed.
