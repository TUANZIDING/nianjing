## 自动验证

`node --test 验证/流程验证v1.0.mjs`：9项通过，0项失败。

| 验证项 | 结果与证据 |
| --- | --- |
| 规则导演 | 保留用户原话、幽默和负面表达；音乐独立修改；布局、时长和画幅修改；输入长度限制 |
| Vidu 合同 | 零参考图生图、单张首帧、10秒、独立音频、Token请求头、state与creations返回字段，均为注入式离线响应 |
| 方舟合同 | 图片URL / Base64、首帧角色、adaptive比例、音频参数、任务返回字段，均为注入式离线响应 |

语法检查：Node服务和界面交互脚本通过。交付检查脚本检查自主文件命名、JSON语法、本地Markdown链接和私人路径 / 会话地址。实际发布包另以Git树导出，排除本地作品和私有配置。

## 实际浏览器验证

本机创作桌已打开。完成课堂案例指令生成、音乐偏好修改、切换指令页；API未配置时直接生成选项保持禁用。

用既有Muse灯笼古镇视频和图片验证文件导入、合成及MP4下载。页面显示「成片已完成」「包含音轨」；浏览器视频duration=10，readyState=4，error=null。下载文件与本地导出SHA-256一致：

`bd50476e824b1d9ac5e6cacbacccbebda7d37aa37d02f9a1494dc223c67681bd`

刷新后能恢复最近作品、预览与下载入口。修正后的四组缩略图保持原始横幅比例；本次视口测得279.5×157.9像素，四张均成功加载。没有观察到浏览器控制台错误。

以上成片是已有素材的导入与本地合成验证，不能称为念景新生成的古镇作品，也不验证API模型的创作质量。桌面可见画面经过检查；手机和不同浏览器尚未逐一实测。
