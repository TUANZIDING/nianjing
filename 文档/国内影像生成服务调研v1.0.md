## 付费与接入条件

- 即梦网页列有会员积分；方舟 API 单独计费，需要账号、模型开通和 API Key。[方舟定价](https://docs.volcengine.com/docs/ark/model-pricing?lang=zh&redirect=1)。Seedance 2.5 开通条件为三者任一：余额大于 200 元、购买 200 元档及以上专属节省计划、已有该系列资源包余量，并非唯一要求充值。[官方教程](https://docs.volcengine.com/docs/ark/seedance-2-5?lang=zh)
- 可灵网页会员与 API 资源包分开；官方快速开始列图片 / 视频资源包和试用包。[API 购买页](https://kling.ai/dev/pricing)。具体人民币价格、国内账户资格未核实。
- Vidu 网页订阅与 API 积分分开；API 需注册登录、创建 Key、充值积分。[常见问题](https://platform.vidu.cn/docs/overview/faq)、[当前价格](https://platform.vidu.cn/pricing)。最低购买量以控制台为准。
- 百炼默认按量计费；北京刊例价列 wan2.7-image 0.20 元 / 张，wan2.7-i2v 720P 0.6 元 / 秒、1080P 1 元 / 秒。[官方价格](https://help.aliyun.com/zh/model-studio/model-pricing)。Key、模型、Endpoint 必须同地域；免费额度和账户状态未核实。

## 音乐能力的关键区别

视频联合生音适合先出完整短片；“画面不变，只换音乐”还需要独立音轨路径。方舟、万相、可灵的有声视频不能直接当作独立纯音乐 API 的证明。

Vidu [可读取的音频文档](https://docs.platform.vidu.cn/331850541e0)确认 POST /ent/v2/text2audio、audio1.0 和 10 秒示例。[新文档的官方搜索索引](https://platform.vidu.cn/docs/text-to-audio)写明 BGM、2～10 秒，但直接打开显示“文档未找到”。因此是默认 10 秒配乐的候选；当前账号可用性、偏好控制及质量仍待实测。

[MiniMax 官方公告](https://platform.minimax.io/docs/api-reference/music-generation)注明：2026-08-20 起付费音乐 / 歌词 API 不再对新用户开放，旧付费用户可继续；免费音乐 API 停用。参数表仍残留免费型号，应以公告为准。可查看[官方 Audio 网页](https://www.minimax.io/audio/music)，勿用旧示例推断新账号 API 可用。

## 项目方案修订

以下是根据本轮讨论形成的设计建议，尚未实现。

- 保留用户目前满意的 Muse 创作流程、提示词和作品作为效果基准；Muse 聊天应用的完整自动接入能力仍待核实。
- 项目自身不设收费、充值或统一余额窗口。第三方生成服务的购买与账户配置由使用者自行完成。
- 官方网页入口用于跳转和复用提示词；API 适配用于在本地工具内自动完成生成。两种路线分别标明，网页链接不记为“自动成片已实现”。
- 图片、动态视频、独立音乐各自允许替换生成服务，支持保留已有画面后单独改配乐。
- 第一版保持温暖的纸上创作桌，一句话输入、摄影与绘画拼接、先出完整作品再对话修改。服务配置放在设置中，首页专注创作。
- 后续贡献者可添加服务入口、API 适配和实测案例。获得确认后才登记为合作关系；一般候选平台使用中性服务名称。
