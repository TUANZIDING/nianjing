## Release 描述草案

念景0.1.0提供一个温暖的纸上创作桌。写一句自己的话，把摄影与纸面绘画组织成同一个故事；在熟悉的多媒体服务生成后导入，也可自行配置方舟和Vidu API。支持独立换配乐、保留视频画面并导出MP4。

本版规则导演尚未接入语言模型；四景为既有Muse作品；API适配器完成离线合同测试，真实账户付费生成与质量待验证。项目自身没有收费或充值窗口。
