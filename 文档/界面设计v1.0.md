# 念景的纸上创作桌

用户已确认：普通人的日常表达、一句话启动、摄影与绘画拼接、先出完整作品再调整、温暖纸感、本地优先、项目不设置自己的收费或充值窗口。

## 设计读法

全新的创作工具。首屏承担“说出想法”和“看见意境”，观看距离是电脑与手机；视觉温度安静、温暖，日常吐槽可在作品中保持幽默。创作区、作品预览和四景示例形成层次，详细指令与服务配置向下展开。

五项刻度：视觉变化 4/10、动态强度 2/10、信息密度 3/10、素材依赖 8/10、品牌一致 8/10。已有真实 Muse 示例承担画面，不用模拟图片冒充生成结果。

## 视觉系统

- 自定义纸感风格，沿用已确认的创作桌方向。
- 纸张 #f5f1e8，墨色 #292c27，陶土色 #966347，浅绿 #7b8570；中性色由这些颜色推导。
- 标题优先使用设备上的宋体（Songti SC / Noto Serif CJK SC），正文使用 PingFang SC / Noto Sans CJK SC，不依赖在线字体。
- 以 8px 为间距基数；主要区块 32—64px，桌面留白随视口变化。
- 纸面基本保持直线轮廓，控件圆角 8px，作品边框 3px；阴影只用于预览框。
- 交互过渡 160ms，轻微位移 2px；遵守减少动态偏好。
- 首屏使用用户既有 Muse 图；视频明确标为既有示例。

## 能力状态

现成示例、生成指令、导入作品和 API 生成分开呈现。没有配置 API 时，界面如实引导外部创作并导入，不能播放示例后宣称完成了新作品。API 适配代码不等同于付费账号实测通过。
