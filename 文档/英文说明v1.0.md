## Start with a thought

No reference photo or prompting skills needed. Write what you want to express, then shape the picture, movement and music.

| A feeling to express | A place to begin |
| --- | --- |
| Humor and a little release | “The lecture is still going, but my mind left class early. Let the notes become paper planes.” |
| A memory worth keeping | “I want to keep that sunset by the sea on a page that gently moves.” |
| Somewhere you long to go | “A little cabin beneath snowy mountains, with a warm light in the window.” |

<a id="quick-start"></a>
## Quick start

Use **Node.js 22+**. Browsing examples and preparing prompts work without FFmpeg; media validation and composition require **FFmpeg and ffprobe**.

```sh
git clone https://github.com/TUANZIDING/nianjing.git
cd nianjing
node 创作服务v1.1.mjs
```

Open the [English creative desk](http://127.0.0.1:8787/?lang=en) or [Chinese creative desk](http://127.0.0.1:8787/?lang=zh).

You can also [download the release package](https://github.com/TUANZIDING/nianjing/releases/latest), unzip it and run the same start command from its project folder. [Full setup and contribution guide](English-guidev1.2.md)

## One idea connects the film

**Your thought → Collage prompt → Motion & music prompts → Create or import → Compose locally → Refine**

| What you want to do | How Nianjing helps |
| --- | --- |
| Express something from scratch | Prepare editable image, motion and music prompts from Chinese or English ideas; copy or save them. |
| Keep photography and drawing together | Keep two distinct materials, a torn-paper edge and one connecting object. |
| Make it feel like you | Choose the paper style, layout, frame, 5/10-second target and your own music preference. |
| Use a familiar creative service | Create in Muse, Hark or another website; import the video and music. |
| Change only the music | Replace the audio while preserving the video picture; original dialogue and environmental sound are also replaced. |
| Use your own API | Configure enabled Volcengine Ark or Vidu models to run the generation workflow. |

Humor belongs here too. [My Mind Left Class Early](../提示词/创作指南v1.1.md) is a bilingual prompt example; no film has been generated for it.

<a id="capabilities"></a>
## Capability status

| Status | Capability | Practical boundary |
| --- | --- | --- |
| Implemented | Bilingual interface, rule-based prompts and conversational revisions | Six scene-template groups, no language model; original user text is not machine-translated. |
| Tested | Examples, import, FFmpeg composition and MP4 export | Local and GitHub workflow tests cover media composition; music replacement preserves the video stream. |
| Offline tested | Ark image/video and Vidu image/video/audio adapters | Paid account generation, music quality and billing remain untested. |
| External creation | Muse, Hark and other official website entries | No complete-film Muse / Hark API connection is claimed. |

No billing, recharge or subscription window. External generation uses your own account. Listed services are candidates, not claimed partners. The application runs on your computer.

<details>
<summary><strong>Bring your own official API</strong></summary>

```sh
mkdir -p 私有
cp 服务配置示例v1.0.json 私有/服务配置v1.0.json
```

Configure your enabled models and API key in the private file, then restart. Direct generation needs both image and video configuration; music is optional. Keys stay on the local server; private configuration and creations are excluded from Git.

Account access, parameters and fees depend on the provider. [Full configuration guide](English-guidev1.2.md)

</details>
