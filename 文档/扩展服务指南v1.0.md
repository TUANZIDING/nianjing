# 服务配置与扩展指南 v1.0

## 自备服务

把根目录的配置示例复制到 `私有/服务配置v1.0.json`。不要将真实配置提交到 Git。环境变量 `VIDU_API_KEY`、`VOLCENGINE_API_KEY` 覆盖文件中的 Key；模型、画幅、分辨率与音频能力须在自己的账户验证。

`imageProvider` 和 `videoProvider` 支持 `vidu`、`volcano`；`audioProvider` 支持 `vidu`。`external` 表示使用外部网站 / 文件导入，无 API 请求。图片与视频必须都配置就绪才开放直接生成，音频不是前置条件。

方舟：`imageModel`、`imageSize`（默认2K）、`videoModel`、`videoResolution`（默认720p）、`nativeAudio`。视频首帧始终使用adaptive；在图片提示词中声明目标画幅，实际比例以模型输出为准。原生音频只对支持它的模型有效。

Vidu：`imageModel`、`imageResolution`（默认1080p）、`videoModel`、`videoResolution`（默认1080p）、`audioModel`、`nativeAudio`。图片调用不上传参考图，必须选择支持文生图的模型。视频传单张首帧，选定模型应支持5/10秒。音频合同仍有新旧文档差异，首次实测须确认参数类型与返回媒体格式。

当独立配乐就绪时，建议关闭 `nativeAudio`；本地合成会用独立音轨替换全部原音轨，原声和环境音也会一并替换。没有独立音轨时沿用视频原音轨，无声视频会在界面明确说明。

本版没有自动额度查询或自动任务重试。任务超时或中断后先到第三方控制台查看任务 ID，避免重复计费。Key 有效不等于模型已开通；配置就绪也不等于真实生成成功。

## 新增适配器

当前统一接口在 `核心/生成接口v1.0.mjs`：

```js
const provider = createProvider(config);
// kind: image / video / audio；image 为视频首帧的 URL 或 data URI
const result = await provider.generate(kind, plan, {image, onTask});
// result: {url} 或 {bytes: Buffer}；不得把任务 ID 当作成片
```

调用方负责下载、大小与媒体校验、保存和合成。provider负责请求认证、模型参数、异步任务状态、成功下载地址和可读失败消息。不要将服务原始错误完整送到浏览器，以免泄露 Key 或账户信息。新增模块使用自然名称和版本号，不含下划线。

贡献流程：

1. 在官方文档核对入口、账户资格、参数、媒体格式和任务状态，记录核验日期。
2. 为各能力明确支持范围，区分官网可用、API合同可读、离线测试通过和真实生成通过。
3. 使用注入式transport写离线合同测试，不在CI调用计费接口。
4. 经使用者授权后做一次最小真实生成，记录模型、时长、分辨率、费用来源及画面 / 音轨质量，不记录Key。
5. 更新服务清单和界面状态。保留用户导入与替换音乐的路径。

## 官方入口与合作窗口

服务清单仅表示候选能力和官方网站。新增真实合作窗口时，需附官方链接、联系目的和当前关系状态；未得到确认时不得写「官方合作伙伴」或放置合作Logo。可以提交扩展建议，但本项目不会自动联系平台或发送用户资料。

## 本地服务的边界

服务只监听本机，拒绝跨来源写入，不提供任意文件读写入口。仅开放登记的示例和当前作品媒体；视频支持Range请求。真实Key仅服务端读取，浏览器获取就绪标志。

公开部署需要另外设计认证、任务隔离、下载网络策略、额度和并发控制、存储保留以及费用确认。本版未提供这些公网能力，不能直接绑定公网接口作为多人SaaS使用。

文件导入只验证媒体流与长度，不对内容合法性或版权作判断。不要把未公开的个人资料写进准备公开的案例或说明。
